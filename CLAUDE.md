The application lives in `board-games-tracker/`; run every `pnpm` command from
there. Project skills in `.claude/skills/` cover the recurring tasks: `check`,
`nextjs`, `react-best-practices`, `drizzle-queries`, `db-schema-change`,
`server-action`, `api-route`, `env-setting` and `ui-component`. The Context7
plugin serves current docs for Drizzle, Better Auth, next-intl, Zod and
Tailwind.
